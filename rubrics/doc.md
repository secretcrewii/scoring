# 문서 · 기획안 채점 기준

사람이 읽을 문서(기획안, 제안서, 공지, 보고서)를 평가합니다.
프롬프트 기준과 다릅니다 — 여기서는 **읽는 사람이 결정을 내릴 수 있는가**가 핵심입니다.

> 2026-08 문서 작성 연구 조사(BLUF/미 육군 AR 25-50, Minto 피라미드, Amazon 6-pager,
> 플레인랭귀지 실측 연구, NN/g 시선추적)를 반영했습니다.
> 근거: [docs/research/doc-review-research-2026-08.md](../docs/research/doc-review-research-2026-08.md)
>
> 전제가 되는 사실 하나: **독자의 79%는 스캔만 하고, 정독하는 사람은 16%입니다** (NN/g 측정).
> 문서는 끝까지 읽히지 않는다는 가정 위에서 채점합니다.

## 채점 항목

### 1. 결론이 먼저 오는가 (25점)

| 점수 | 상태 |
|---|---|
| 22~25 | 첫 문단에 목적("왜 이 문서가 존재하는지")과 결론·요청이 함께 있고, **제목부터** 결론을 담음 ("OO 도입 시 비용 30% 절감 예상") |
| 15~21 | 결론은 있으나 중반에 묻혀 있음 |
| 8~14 | 끝까지 읽어야 결론이 나옴 |
| 0~7 | 다 읽어도 무엇을 하자는 건지 모름 |

**가점**: 첫 문단만 읽고 멈춰도 전체 요지를 아는 역피라미드 구조 (NN/g 권고).
**감점**: 기승전결식 전개 (결론을 뒤로 미룸), 제목이 결론 없는 주제 명사("OO 관련 보고"),
배경 설명이 결론보다 긺.

### 2. 근거가 붙어 있는가 (25점)

| 점수 | 상태 |
|---|---|
| 22~25 | 주장 **바로 아래에서** 근거가 이어지고(수직 Q&A — 독자가 "왜?"라고 묻는 순간 다음 문장이 답함), 주요 주장마다 숫자·출처 |
| 15~21 | 핵심 주장에만 근거가 있음 |
| 8~14 | 근거가 한두 개뿐 |
| 0~7 | 근거 없이 주장만 |

**가점**

- 기획안·제안서에서 **검토한 대안 2~3개 + 기각 사유**가 있음 — 결정 준비가 된 문서의 요건
- 결정권자가 던질 첫 반문에 문서 안에 답이 있음 (Amazon PR-FAQ 방식)
- 상세 데이터·표는 부록으로 빼고 본문은 서술로 유지 (Amazon 6-pager 방식)

**감점**: "상당히", "크게" 같은 수치 없는 수식어가 숫자를 대신함, 같은 근거가 여러 항목에 중복
등장, 본문이 소화 안 된 표 덤프로 채워짐.

### 3. 읽는 사람이 정해져 있는가 (25점)

| 점수 | 상태 |
|---|---|
| 22~25 | 대상 독자의 관심사·결정 권한에 맞춰 쓰였고, 결정 요청 문서라면 **단일 결정권자 1인**이 특정됨 |
| 15~21 | 대상은 짐작되나 일부 내용이 어긋남 |
| 8~14 | 누가 읽을지 고려하지 않음 |
| 0~7 | 작성자만 이해할 수 있음 |

**가점**: 도입이 독자가 이미 아는 사실에서 출발해 "무엇이 달라졌는가"로 넘어감 (Minto SCQA).
**감점**: 독자가 모를 전문용어·내부 약어를 설명 없이 씀 (미국은 이걸 법으로 금지합니다 —
Plain Writing Act 2010), 경영진·실무자·외부를 한 문서에 뭉뚱그림, 독자가 다 아는 배경을 길게 반복.

### 4. 다음 행동이 분명한가 (25점)

| 점수 | 상태 |
|---|---|
| 22~25 | **누가(실명), 무엇을, 언제까지**가 한 문장에 있고, 문서가 원하는 것(승인/공유/의견)을 스스로 밝힘 |
| 15~21 | 할 일은 있으나 담당자나 기한이 빠짐 |
| 8~14 | "검토 바랍니다" 수준 |
| 0~7 | 다음 행동이 없음 |

**가점**: 요청(ask)이 문서 첫 두 줄 안에 등장, 첫 마일스톤에 확정 기한.
**감점**: 실행 책임이 위원회·부서명으로 뭉뚱그려짐 (기한 없는 요청은 독자의
"언젠가 할 일 더미"로 밀립니다).

## 공통 감점: 문장 부담 (최대 -10점)

네 항목을 다 만족해도 문장이 길고 장황하면 이해가 실측으로 무너집니다 —
**평균 8단어 문장에서 이해도 100%, 43단어에서 10% 미만.** 플레인랭귀지로 고친 미 해군
메모는 읽기 시간을 17~23% 줄였고, 미 보훈부 안내문 하나를 고치자 문의 전화가
1,100건에서 200건 미만으로 떨어졌습니다.

- 한 문장에 세 가지 내용이 들어간 만연체가 반복됨: -5
- 같은 내용의 중복 서술: -3
- 불필요한 격식·수동태 남발("~된 바 있음", "~하도록 함"): -2

## 점수대별 총평

| 총점 | 서술 |
|---|---|
| 90~100 | 그대로 보내도 되는 문서 |
| 80~89 | 한 군데만 다듬으면 됨 |
| 70~79 | 읽는 사람이 한 번은 되물을 문서 |
| 60~69 | 회의를 한 번 더 해야 하는 문서 |
| 60 미만 | 다시 쓰는 편이 빠름 |

## 리뷰할 때 반드시 할 것

- **고쳐 쓴 첫 문단**을 보여줍니다. 결론을 앞으로 뺀 버전 한 문단이면 무엇을 말하는지 바로 전달됩니다.
- **문서의 목적**(설득인지, 공유인지, 승인 요청인지)을 먼저 확인하고 그 기준으로 봅니다.
  공지라면 근거(②)보다 행동(④)을 무겁게, 보고서라면 결론(①)·근거(②)를 무겁게 보세요.
- 지적은 **가장 큰 것 하나부터** 합니다. 오탈자는 언급하지 않습니다 (요청받았을 때만).
- 문서가 길면 전체를 읽되, 지적은 결정에 영향을 주는 것만 합니다.
