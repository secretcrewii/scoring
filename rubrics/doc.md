# 문서 · 기획안 채점 기준

사람이 읽을 문서(기획안, 제안서, 공지, 보고서)를 평가합니다.
프롬프트 기준과 다릅니다 — 여기서는 **읽는 사람이 결정을 내릴 수 있는가**가 핵심입니다.

## 채점 항목

### 1. 결론이 먼저 오는가 (25점)

| 점수 | 상태 |
|---|---|
| 22~25 | 첫 문단에서 무엇을 하자는 건지 알 수 있음 |
| 15~21 | 결론은 있으나 중반에 묻혀 있음 |
| 8~14 | 끝까지 읽어야 결론이 나옴 |
| 0~7 | 다 읽어도 무엇을 하자는 건지 모름 |

**감점 사유**: 배경 설명이 결론보다 길다, 제목이 내용을 안 담고 있다.

### 2. 근거가 붙어 있는가 (25점)

| 점수 | 상태 |
|---|---|
| 22~25 | 주요 주장마다 숫자나 출처가 붙음 |
| 15~21 | 핵심 주장에만 근거가 있음 |
| 8~14 | 근거가 한두 개뿐 |
| 0~7 | 근거 없이 주장만 |

**감점 사유**: "많은", "대부분", "크게" 같은 표현이 숫자를 대신하고 있음.

### 3. 읽는 사람이 정해져 있는가 (25점)

| 점수 | 상태 |
|---|---|
| 22~25 | 대상 독자의 관심사와 결정 권한에 맞춰 쓰여 있음 |
| 15~21 | 대상은 짐작되나 일부 내용이 어긋남 |
| 8~14 | 누가 읽을지 고려하지 않음 |
| 0~7 | 작성자만 이해할 수 있음 |

**감점 사유**: 내부 약어를 외부 독자용 문서에 그대로 씀, 경영진용 문서에 구현 세부사항이 가득함.

### 4. 다음 행동이 분명한가 (25점)

| 점수 | 상태 |
|---|---|
| 22~25 | 누가, 언제까지, 무엇을 할지가 명시됨 |
| 15~21 | 할 일은 있으나 담당자나 기한이 빠짐 |
| 8~14 | "검토 바랍니다" 수준 |
| 0~7 | 다음 행동이 없음 |

## 점수대별 총평

| 총점 | 서술 |
|---|---|
| 90~100 | 그대로 보내도 되는 문서 |
| 80~89 | 한 군데만 다듬으면 됨 |
| 70~79 | 읽는 사람이 한 번은 되물을 문서 |
| 60~69 | 회의를 한 번 더 해야 하는 문서 |
| 60 미만 | 다시 쓰는 편이 빠름 |

## 리뷰할 때 반드시 할 것

- **고쳐 쓴 첫 문단**을 보여줍니다. 결론을 앞으로 뺀 버전 한 문단이면 무엇을 말하는지 바로 전달됩니다.
- 지적은 **가장 큰 것 하나부터** 합니다. 오탈자는 마지막입니다.
- 문서의 목적(설득인지, 공유인지, 승인 요청인지)을 먼저 확인하고 그 기준으로 봅니다.
