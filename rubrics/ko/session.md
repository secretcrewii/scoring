# 세션 채점 기준

한 번의 작업 세션 전체를 돌아보며 평가합니다. 개별 프롬프트가 아니라 **일을 시키는 방식**을 봅니다.

> 2026-08 프롬프팅 연구 조사에서 세션 습관에 해당하는 결과를 반영했습니다.
> 근거: [docs/research/prompting-research-2026-08.md](../docs/research/prompting-research-2026-08.md)

## 채점 항목

### 1. 첫 지시의 완성도 (25점)

세션의 첫 프롬프트가 얼마나 준비되어 있었는가. `rubrics/prompt.md` 기준을 그대로 적용합니다.

첫 지시가 좋으면 세션 전체가 짧아집니다. 여기가 세션 품질의 8할입니다.
성과 좋은 프롬프트는 평균 21단어, 보통의 첫 프롬프트는 9단어 미만입니다 (Google 측정).

| 점수 | 상태 |
|---|---|
| 22~25 | 첫 프롬프트만으로 원하는 결과의 8할이 나옴 |
| 15~21 | 한두 번 되묻고 나서 궤도에 오름 |
| 8~14 | 서너 번 주고받은 뒤에야 방향이 잡힘 |
| 0~7 | 세션 중반까지 무엇을 원하는지 정리되지 않음 |

**가점**: 큰 작업에서 "계획부터 보여줘, 승인하면 시작해"로 연 경우 (OpenAI 실측 성공률 +4%p).
단, 한 문장짜리 작은 일에 계획을 시킨 건 가점 아님 — 과잉 절차입니다.

### 2. 되돌아간 횟수 (25점)

같은 것을 다시 시키거나, 앞서 한 작업을 되돌린 횟수.

| 점수 | 상태 |
|---|---|
| 22~25 | 되돌림 없이 앞으로만 진행 |
| 15~21 | 한 번 정도 방향 수정 |
| 8~14 | 두세 번 되돌아감 |
| 0~7 | 반복적으로 되돌아가 진척이 없음 |

**감점 사유**: 되돌아간 이유가 *AI의 실수*가 아니라 *지시의 모호함*이었을 때 더 크게 감점합니다.

**가점**: 같은 지적이 2회를 넘었을 때 **대화를 갈아탄** 경우 — 실패에서 배운 조건을 담아
새 대화를 시작하는 것이 계속 고치는 것보다 거의 항상 빠릅니다 (Claude Code 공식 권장).
반대로, 10번 넘게 같은 결과물을 땜질하며 세션을 끌었다면 감점입니다.

### 3. 피드백의 구체성 (25점)

결과가 마음에 안 들 때 무엇을 어떻게 고치라고 했는가.

| 점수 | 상태 |
|---|---|
| 22~25 | 지점 + 조치 + 기준을 함께 지시 ("3번 항목이 근거가 없다. 출처를 붙여줘") |
| 15~21 | 어디가 문제인지는 짚었으나 어떻게 고칠지는 안 말함 |
| 8~14 | "별로다", "다시" 수준 |
| 0~7 | 불만만 표현하고 방향을 안 줌 |

**연구 메모**: 기준 없는 "다시 검토해줘"는 효과가 없고 맞은 답을 틀리게 고치기도 합니다
(ICLR 2024). "①합계 ②부가세 적용, 두 가지만 확인해줘"처럼 기준을 준 검토 지시가 만점 기준입니다.
전체 재작성 대신 부분 수정 지시("두 번째 문단만 절반으로")도 가점 요소입니다.

### 4. 마무리 (25점)

세션이 결론에 도달했는가, 그리고 다음에 쓸 수 있는 것을 남겼는가.

| 점수 | 상태 |
|---|---|
| 22~25 | 결론에 도달했고 재사용할 프롬프트나 문서를 남김 |
| 15~21 | 결론은 났으나 남긴 것이 없음 |
| 8~14 | 흐지부지 끝남 |
| 0~7 | 중간에 멈췄고 무엇을 했는지도 불분명 |

**연구 메모**: 잘 작동한 프롬프트의 저장·재사용이 "만능 문구 찾기"보다 실질적인 개선 경로입니다
(Wharton — 같은 문구도 과제별로 효과가 ±60%p 요동). 세션에서 좋은 프롬프트가 나왔는데
저장하지 않고 끝났다면, `/save-prompt`를 마무리 제안으로 꼭 안내하세요.

## 세션 리뷰에서 반드시 할 것

1. **반복된 약점 하나를 지목합니다.** 세션 내내 같은 항목이 계속 낮았다면 그게 진짜 개선 지점입니다.
2. **가장 좋았던 프롬프트 하나를 짚어 칭찬합니다.** 무엇이 좋았는지 이유까지 말합니다.
   그 프롬프트가 재사용 가치가 있으면 `/save-prompt`로 저장을 권합니다.
3. **다음 세션에서 시도할 것 한 가지**를 제안합니다. 여러 개 주면 하나도 안 합니다.
